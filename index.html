CVCONFIG VAULT Browser ထဲမှာသာ အလုပ်လုပ်သည်

သင့်ဖိုင်၊ သင့်စက်၊ သင့်ထိန်းချုပ်မှု

Config ဖိုင်တွေကို
ကိုယ်တိုင် ကာကွယ်ပါ။

သင့်ကိုယ်ပိုင်ဖိုင်ကို စကားဝှက်ဖြင့် encrypt လုပ်ပါ၊ လိုအပ်သည့်အခါ ပြန်ဖွင့်ပါ။ ဖိုင်ကို server သို့ မပို့ပါ။

ခိုင်မာပြီး မျှဝေမထားဖူးသော စကားဝှက်ကို အသုံးပြုပါ။ မေ့သွားလျှင် ဖိုင်ကို ပြန်ဖွင့်၍မရပါ။

အခြား VPN app များ၏ သီးသန့် lock ဖိုင်များကို ဒီ tool ဖြင့် ဖွင့်၍မရပါ။

⌑

လုံခြုံရေးအကြောင်း

ဖိုင်ကို သင့် browser မှာပဲ Web Crypto API ဖြင့် AES-256-GCM ချစ်ပ်ဝှက်သည်။ Password မှ key ရယူရာတွင် PBKDF2-SHA-256 အသုံးပြုသည်။ ဒီစာမျက်နှာက ဖိုင် သို့မဟုတ် password ကို network မှတစ်ဆင့် မပို့ပါ။
